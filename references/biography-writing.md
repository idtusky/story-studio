# 人物故事写作适配

当前专用 profile 是 `yuling-characterstory`，来源为 characterstory-writing。其主要风格基于玉玲2711真实历史女性故事；后续新增的其他账号原稿不等于已重新蒸馏并验证该风格，也不据此自动扩大适用人群。

## 读取与执行

1. 先读 [事实与风格优先级](fact-and-style.md)。人物名、核心事件、目标字数和系列集数能从请求得到就直接使用；没有系列要求不强制拆成2–3集。
2. 读 [人物模块](../modules/characterstory-writing/GUIDE.md)、其 Writing-DNA.md、开头钩子DNA.md、文章结构模板.md、语言DNA.md、写作视角与认知框架.md。视觉风格指南.md 是标题和节奏参考，不替代配图画风选择。
3. 先核实生平、时间线与核心转折，再选择能由事实支撑的钩子和结构。没有资料支撑的“苦难—坚守”弧线不硬套；可换已证事件，说明原模板不适用。对不在该专用风格适用范围的人物，可按用户要求写普通人物传记，记录 `writing_profile=general-biography`，不称已验证玉玲风格，也不强制切回历史分析。
4. 精确数字和场景细节遵守事实规则；“三不省略”等模板要求只在证据与用户要求允许时应用。不要为凑齐模板制造数字或经历。
5. 根据单集或系列安排背景、崛起、转折与结局。系列续写优先读取已有集，避免同一事件重复讲完、年龄或身份衔接错误；没有前集材料时不杜撰“上回说到”。
6. 保存纯正文，使用 `modules/history-writing/scripts/history_tool.py count` 进行字数检查。指定“N字”严格N，“约N字”默认±5%，用户口径优先。人物稿不要用历史库的低相似结果宣称已对人物库完成查重；必要时实际比对所参考的人物原稿。

## 资源边界

- 模块 corpus/ 内的原文保留为写法与选题参考；按当前人物和写法选择性阅读，不默认一次加载全部文件。
- 选题策略DNA.md 只在选题时读取。带货融入节点DNA.md 仅在用户明确要求商业内容时参考；它不是默认口播任务的一部分，不能自动加入带货。
- 模板中的性别、磨难和传播号召是特定风格的条件，不是所有人物故事赛道的全局规则。新风格按 [扩展说明](extending.md) 单独接入。
