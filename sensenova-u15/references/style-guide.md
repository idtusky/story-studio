# SenseNova U1.5 风格与提示词指南

> 通用提示词素材：风格、构图、光线、色彩词汇与中文场景模板，适用于 U1.5 Lite / Fast 的生成与编辑。
>
> **使用前提**：U1.5 默认开启 `prompt_extend` 自动润色，描述清楚完整即可，无需堆砌模板；但**风格、构图、光线等选型词汇**自动润色不会替你决定，本指南即为此服务。按需取用，不要整段照抄。

---

## 一、艺术风格速查

### 写实摄影 (Photorealistic)

**关键词：** 超写实、高细节、真实光影、自然纹理、高分辨率
**适用场景：** 风景、人像、产品、建筑

**技巧：** 描述具体光线（黄金时刻、柔和散射光、戏剧性逆光），添加质量标记（超高清、锐利细节）。

```
写实摄影，城市夜景，雨后的街道，霓虹灯倒影，高细节，超高清
```

### 油画 (Oil Painting)

**关键词：** 油画风格、笔触、画布纹理、颜料质感
**适用场景：** 风景、肖像、静物

| 流派 | 关键词 | 特点 |
|------|--------|------|
| 印象派 | 印象派、莫奈风格、粗犷笔触 | 色彩丰富，光影朦胧 |
| 写实派 | 写实油画、古典油画 | 细节精确，光影深邃 |
| 抽象派 | 抽象油画、表现主义 | 形式自由，情感强烈 |

```
油画风格，秋日山村，金色落叶，晨雾缭绕，印象派笔触，厚重颜料质感，暖色调
```

### 水墨画 (Chinese Ink Wash)

**关键词：** 水墨风格、国画、写意、工笔、宣纸、留白
**适用场景：** 山水、花鸟、古风

| 技法 | 关键词 | 特点 |
|------|--------|------|
| 写意 | 写意、泼墨、抽象 | 自由奔放，重意境 |
| 工笔 | 工笔、勾勒、精细 | 线条分明，细节精致 |
| 青绿 | 青绿山水、石青石绿 | 色彩艳丽，富丽堂皇 |

```
水墨风格，写意山水，淡墨渲染，远山近水，留白，几点红色点缀
```

### 动漫 / 二次元 (Anime)

**关键词：** 动漫风格、二次元、赛璐璐、日系插画
**适用场景：** 角色设计、场景插画

| 风格 | 关键词 | 特点 |
|------|--------|------|
| 新海诚风 | 新海诚风格、耀眼光线、云彩 | 光影绚丽，场景唯美 |
| 宫崎骏风 | 宫崎骏风格、治愈、田园 | 温馨自然，童话感 |
| 赛璐璐风 | 赛璐璐着色、平涂、清晰线条 | 色彩块面分明，线条干净 |

```
动漫风格，夕阳下的学校天台，金黄色调，新海诚风格，耀眼逆光，云彩细节
```

### 赛博朋克 (Cyberpunk)

**关键词：** 赛博朋克、霓虹、未来都市、蓝紫色调、高对比度

```
赛博朋克，未来都市，霓虹灯牌，雨夜街道，全息投影，潮湿路面倒影，蓝紫色调，高对比度
```

### 3D 渲染 (3D Render)

**关键词：** 3D渲染、C4D、Blender、光线追踪
**适用场景：** 产品展示、建筑可视化

```
3D渲染，未来感跑车，红色金属漆面，C4D渲染，工作室布光，光滑反射，8K分辨率
```

## 四、构图指南

### 景别

| 景别 | 英文 | 适用场景 |
|------|------|---------|
| 特写 | Close-up | 面部表情、产品细节 |
| 中景 | Medium shot | 人物半身、对话场景 |
| 全景 | Full shot | 全身人像、小场景 |
| 远景 | Wide shot | 风景、建筑、大场景 |
| 极远景 | Extreme wide | 航拍、大场景 |

### 拍摄角度

| 角度 | 英文 | 效果 |
|------|------|------|
| 平视 | Eye-level | 自然、亲切 |
| 俯视 | High angle | 俯瞰、弱小感 |
| 仰视 | Low angle | 威严、宏大感 |
| 过肩 | Over-the-shoulder | 沉浸感、对话 |
| 侧面 | Profile | 轮廓、剪影 |

### 构图法则

| 法则 | 英文 | 说明 |
|------|------|------|
| 三分法 | Rule of thirds | 主体放在三分线交点 |
| 对称构图 | Symmetrical | 庄严、平衡 |
| 引导线 | Leading lines | 引导视线到主体 |
| 框架构图 | Framing | 用前景框住主体 |
| 黄金比例 | Golden ratio | 自然和谐的比例 |
| 对角线 | Diagonal | 动感、张力 |

## 七、质量标记

在提示词末尾按需加入，不必全堆：

- **分辨率**：超高清、高细节、锐利细节、高分辨率
- **质感**：自然皮肤纹理、织物纹理、金属光泽、光滑/粗糙质感
- **焦距**：浅景深 / 背景虚化、焦内锐利、全焦段清晰
- **工艺**：电影级调色、商业摄影品质、自然真实光影

## 八、图像编辑提示词

U1.5 生成与编辑同一链路：传参考图即进入编辑模式（`--images`，本地文件路径或公网 URL，最多 5 张，第一张为主图；编辑模式 `size` 默认 `auto` 自动适配主图）。**与部分厂商不同：本地文件直接传路径即可，无需先上传图床。**

### 编辑模板

```
背景替换：将背景改为[新背景描述]，保持[主体]的[面部/姿势/服装]不变，[新背景]的光线与主体协调
风格转换：将图中[主体]转换为[目标风格：动漫/油画/水彩]，保留[主体特征：面部/轮廓/颜色]
颜色调整：将图中[元素]的颜色改为[新颜色]，保持其他部分不变，自然过渡
多图合成：将提供的图片融合在一起，[描述合成方式]，[每张图保留的元素]，[最终效果描述]
```

### 编辑注意事项

1. **描述变化** — 告诉模型要改什么，而不是重新描述整张图
2. **明确保留项** — 提到不需要改变的部分（如面部特征、构图比例），否则整图容易大改
3. **光线协调** — 替换背景/添加元素时，说明与主体原光线保持一致
4. **参考图指代** — 多张参考图时用"图一/图二"指代（如"参考图二的服装风格重绘图一的人物"）
