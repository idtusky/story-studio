# 正文画风参考图库

在实际生图前读取本文件及已选择的styles规则，按同组参考执行。仅维护技能或讨论使用方法时不触发生图。只做分镜/提示词时可查看参考以理解画风，但不调用生图工具。

## 生图前：选图、查看、传入

1. 根据本项目已确认的style_id选组，不从题材、人物性别或文件夹名推定画风。同组通常选1—3张：一张主要视觉基准，按镜头需要补人物/物件/环境参考。不要一次混传两个风格组，也不要求每镜传完6张。
2. 实际打开本次选用的图片，核对索引描述与可见内容。文件名、旧分镜文字与已生成图片可能不一致，以实际图像为准；缺失、损坏或哈希不一致时说明缺口，不称已经查看。
3. 将正文参考标为“仅参考画风、材质、光线与灰阶/配色”。本期人物身份与年龄参考、时代设定、动作构图分别提供；真实人物的已核验分期资料优先，不用图库中的脸代替目标人物。
4. 在所用生图工具支持参考图片时，通过该工具的真实图片输入传入选中图，使用运行时解析出的绝对路径；仅在提示词里写文件名不算传图。工具不支持或不能传入时保留文字风格规则，并记录本次为text_only，不伪称参考图已注入。
5. 为同一项目固定主要视觉基准，批次之间保持其ID；本期首张已核验图片可作为连续性辅助，但保留原始风格基准，避免只用上一张图逐张接力导致漂移。用户明确要求改风格时再更新基准。

建议在项目STORYBOARD.json或既有制作记录中添加以下字段；不要求用户手填，不改动原镜号：

```json
{
  "style_id": "historical-comic",
  "style_reference_ids": ["HC03", "HC04"],
  "style_reference_roles": {
    "HC03": "主要画风、色层与脸手/背景笔触关系",
    "HC04": "关键物件材质与局部光照"
  },
  "style_reference_delivery": "pending",
  "style_review_status": "pending"
}
```

style_reference_delivery按实际执行填写pending、attached、text_only或unavailable。只有工具实际接收了图片输入才写attached；style_review_status在真实查看本期生成图后更新为matched或needs_revision，不能仅凭工具返回成功填写matched。

## 首图与续图核验

本项目首张实际生成图先与主参考对照，再继续批量生成：看绘画/摄影材质、笔触粗细或灰阶、明暗层次、脸手可读性和主体与背景关系。同时核对本镜人物、时期与动作；画风匹配不等于内容正确。

后续抽查各批次及明显换景、换时期的镜头。出现彩色黑白串用、摄影/厚涂串用、全图过暗或人物被参考图替换时，先做有针对性的修正，遵循主模块的修正次数与交付规则。若工具不能保留视觉参考或结果仍不匹配，如实报告，不保证跨模型完全一致。

正文图库不用于默认封面排版。封面继续使用各自封面规则和已有封面参考，身份照片仍按[真实人物分期参考流程](person-photo-reference.md)处理。

## 资源维护

图像以像素保持不变的PNG副本收录，去除非必要附加信息，原始创作文件不随包分发。索引中的像素哈希可用于核对画面，文件哈希用于核对分发版本。

替换参考时先实际查看候选，确认其属于同一画风，并检查脸手、材质、文字/水印及隐私信息，再更新索引哈希和本文件。通用包只保存相对路径；不加入原素材磁盘地址、电脑用户名、凭据或私人会话。成品参考的收录不附带新的再分发许可，仍遵守项目的内容与许可说明。
