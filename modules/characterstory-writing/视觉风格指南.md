# 视觉风格指南 — 玉玲2711「人物故事」

> 本账号为视频号纯口播形式，无图文混排、无字幕花字、无背景音乐文字叠加。
> 「视觉风格」落点在：**标题文案**、**封面文字截取**、以及**口播节奏对画面节奏的替代**。

---

## 一、标题文案公式

### 基础结构
```
[数字排列 / 极端起点] + [反常转折 / 时代压迫] + [情感定性结局]
```

### 三种变体

**A. 数字连排型**（适合集1，建立人物底色）
```
她[年龄]X，[年龄]Y，[年龄]Z，[结局]。
```
- 「她六岁丧父，随母亲做女佣，十六岁出道，九年拍二十九部电影，成为默片皇后。她演尽苦命女人，二十五岁却服药离世，三十万人为她送葬。」
- 「四五岁丧母的彝族姑娘，17岁一个回眸成了国际影后，18岁让46国观众倾倒。可就在巅峰时，一场风暴将她推入深渊。」

**B. 行为场景型**（适合集2/3，具象化最强戏剧性）
```
[反常行为/极端场景]，[年数/时间]，[情感定性]。
```
- 「银幕上的阿诗玛疯了半生，丈夫装听见她的幻觉陪她演戏27年。她58岁离世，他用余生传她名字。这种爱比任何银幕传奇都动人。」

**C. 宿命宣判型**（高度凝练，集1强用）
```
他/她一生只[最简化的定语]，这就是他/她的一生。
```
- 「他一生只演了两部电影，一部是喜剧，一部是悲剧」（直接成标题或口播开头）

---

## 二、标题语言规范

### 数字写法
| 位置 | 规范 |
|------|------|
| 标题正文中 | 用汉字（「六岁」「二十五岁」「三十万人」） |
| 数字连排密集处（追求视觉冲击） | 用阿拉伯数字（「17岁」「46国」「27年」） |
| 精确时间 | 始终阿拉伯数字（「1935年3月8日」） |

### 标点规范
- 用句号，不用感叹号（句号留白产生张力，感叹号廉价化情绪）
- 一个标题最多一个问号，且只出现在极少数悬念型标题
- 短句停顿用逗号，段落之间用句号

### 禁止词
- ❌ 令人泪目、催泪、感人肺腑（情绪形容词，让读者提前抵抗）
- ❌ 第一名、最厉害（超级比较级，廉价化）
- ❌ 震惊！、没想到（标题党词汇，与账号调性不符）
- ❌ 她的故事让我……（叙述者插入自我，破坏旁观者视角）

## 三、封面文字截取规则

封面文字从正文中截取最强「反差句」或「数字炸弹句」，原则：

1. **优先截取数字连排句**（最抓眼球）
   - 「6岁丧父 16岁出道 25岁离世 30万人送葬」

2. **次选行为反差句**（制造好奇）
   - 「丈夫装听见她的幻觉 陪她演戏27年」

3. **截取长度**：10-22字最佳（短到可以一眼读完，长到能传递完整意象）

4. **不用完整句子标点**（封面用断句，不用「。」结尾）

---

## 四、口播节奏对视觉节奏的替代

由于纯口播无画面支撑，语言节奏本身承担视觉节奏的作用：

| 视觉手法 | 口播对应手法 |
|---------|------------|
| 快切蒙太奇 | 短句密集排列（「6岁/16岁/25岁」） |
| 定格特写 | 单独成句的金句（前后留逗号或短停顿） |
| 慢推镜头 | 长句展开场景细节（「临走的时候还亲了主人家的两个孩子，谁也看不出这个笑着吻别孩子的女人几个小时后就要吞药」） |
| 黑场+字幕 | 「下集见」（单句，留白） |

---

## 五、系列封面/标题一致性

同一人物的3集，标题/封面在视觉识别上需有连续性：

- 集1：建立人物标签（「[人物名]+最强成就/天才标签」）
- 集2：切入最黑暗（「[人物名]+被[X]毁掉/摧毁」）
- 集3：结局/反转（「[人物名]+[N年后/离世后]+[意外守护]」）

使用同一人物名作为系列锚点，让算法和观众都能识别系列归属。
