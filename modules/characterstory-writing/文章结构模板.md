# 文章结构模板 — 玉玲2711「人物故事」

> T型命运回溯结构：结局/极端场景先抛，再沿时间线正向展开。

---

## 一、单集标准结构（T型命运回溯）

```
【钩子层】30-80字
  ↓
  极端场景 / 数字连排 / 结局先行
  → 「您说……怎么会……」设问（或直接）
  → 姓名揭晓（先描述，后点名）

【背景层】100-200字
  ↓
  出生时间+地点+家庭起点
  必含：早年不幸（丧亲/贫困/阶层低）
  + 命运第一次转机（被发现/被选中）

【崛起层】200-300字
  ↓
  才华展现 + 精确数字支撑的成就
  + 巅峰时刻（最光辉的那一刻）
  末尾埋转折悬念：「可谁也没想到……」

【磨难层】200-400字
  ↓
  一场或多场具体磨难（场景还原，非概述）
  + 情感细节（对话/遗言/细节道具）
  + 「您说……」推进共情
  每段磨难之间用「可」「偏偏」「竟」衔接

【结局/升华层】100-200字
  ↓
  结局交代（精确时间+平静语气）
  + 金句升华（真正的X不是Y，而是Z）
  + 传播号召语

【下集悬念】可选，30-50字
  ↓
  预告下集核心矛盾/反转
  + 「下集见」
```

---

## 二、各层写法细则

### 钩子层（详见《开头钩子DNA》）
- 字数：30-80字（集1稍短，续集可略长含上集回顾）
- 核心动作：制造「这怎么可能」的认知缺口
- 姓名最晚在第二句揭晓，不能一开口就报名字

### 背景层
- 必有的元素：精确出生年+地点+第N个孩子（如有）
- 必有的不幸：极贫 / 早年丧亲 / 社会地位极低
- 叙述语气：平静陈述，不煽情，让事实本身说话
- 节奏：短句，2-3个细节即可，不铺陈

### 崛起层
- 核心任务：让观众明白这个人有多了不起，才能感受后来的落差
- 必须有精确数字（年龄、年份、获奖名称、片名）
- 「那个…的小姑娘，站上了…」的对比句型高频出现
- 末尾不能没有「可谁也没想到」类的转折钩子，否则结构断裂

### 磨难层
- 不能概述，必须场景还原：
  - ❌「他遭受了严重的家暴」
  - ✅「遗书中写道：没有你那晚打我，今晚又打我，我大约不会这样做吧」
- 情感细节道具（手里攥的耳环、骨灰分成两份、装作也能听见幻觉）
- 多段磨难叠加时用「还不够/这还不是最坏的」升级
- 「您说……」在磨难积累到顶点时出现，引爆情感

### 结局层
- 死亡/离世用平静语气，精确时间
  - 「1935年3月8日，25岁的阮玲玉永远地走了」
  - 「2000年7月21日，58岁的杨立坤在上海家中平静离开」
- 金句在结局后，不在前
- 传播号召语必须含「值得被更多人知道」或「让更多人知道」

## 三、三集系列节奏模板

### 集1：身份建立集（「这个人是谁，她多厉害」）
- 重心：天赋展现 + 巅峰成就
- 结尾：磨难悬念（「可就在这时，一场风暴……」）
- 结构比例：背景20% / 崛起50% / 磨难预告30%
- 传播号召语：强调「这种天才值得被更多人知道」

### 集2：磨难深挖集（「她经历了什么」）
- 重心：最黑暗时期的具体细节，情感密度最高
- 开头：接续集1，「上回说到……」或直接切入最黑暗场景
- 结尾：悬念（「可故事还没结束……」）或泪点金句
- 结构比例：磨难核心70% / 挣扎转机20% / 下集预告10%
- 传播号召语：强调「让更多女人知道……」

### 集3：结局/反转集（「最后怎么样了」）
- 重心：往往有意外角度（丈夫的坚守/子孙守护/时代平反/后世记忆）
- 开头：续集承接，或直接抛最感人的细节
- 结尾：最强金句 + 情感最浓的传播号召语
- 结构比例：结局反转50% / 情感升华30% / 金句+号召20%

---

## 四、传播号召语三种变体（可替换使用）

```
A. 知识/天才型
「[如果你觉得这个姑娘了不起/这种坚守值得敬佩]，
就帮我传出去，不是为了给谁涨粉，
是[人物名+核心价值标签]值得被更多人知道。」

B. 情感共鸣型
「如果你身边也有[相似境遇的人]，
把这个故事转给他看看。
[人物名]的故事值得被更多人听见。」

C. 历史正名型（用于末集，激活使命感）
「[人物名]不该被遗忘，
你帮我传一传，让更多人知道这个名字。」
```

## 五、结构禁忌

- ❌ 开篇直接报人名（「今天给大家讲讲田华……」）
- ❌ 结构平铺：生平时间线顺讲，无起伏
- ❌ 磨难层用概述替代场景（「他遭遇了很多困难」）
- ❌ 金句放在磨难层中间，应压轴在结局后
- ❌ 没有「您说」推进句（无此句，情感锚点缺失）
- ❌ 传播号召语省略或简化为「点赞关注」
