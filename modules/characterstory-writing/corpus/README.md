# characterstory-writing 语料库

## 概述

本目录包含用于 characterstory-writing skill 的对标账号文案语料库。所有文案均为真实历史女性人物故事短视频口播稿，采集自视频号平台的头部账号。

## 语料统计

| 账号名 | 文案数量 | 来源时间 | 账号特点 |
|--------|---------|---------|---------|
| 红颜旧事志 | 64篇 | 未保留采集时间 | 聚焦民国及近代传奇女性，情感浓度高，注重人物命运转折 |

## 文件格式

每个文案文件均为 Markdown 格式，结构如下：

```markdown
---
title: [标题]
account: [账号名]
platform: 视频号
---
## 原始发布文案
> [简短钩子文案]
## 口播逐字稿
[完整口播内容]
```

## 使用说明

这些语料用于：

1. **选题策略蒸馏**: 分析各账号为什么选这个人物、为什么讲这个角度、如何发现选题
2. **开头钩子优化**: 提取更多钩子类型和变体，扩充开头钩子DNA
3. **带货融入节点研究**: 识别文案中的带货方式，总结带货时机和话术模板
4. **写作风格参考**: 学习不同账号的叙事节奏、语言风格和结构特点
