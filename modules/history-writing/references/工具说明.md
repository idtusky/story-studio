# 工具说明

Python 3.9 或更高版本，仅标准库。Windows 建议 `python -X utf8`。以下命令在技能目录运行；也可将脚本换成绝对路径。文件参数传入本次项目中的纯正文文件，路径含空格时加引号。

```powershell
python -X utf8 scripts/history_tool.py search --era 西汉 --limit 5
python -X utf8 scripts/history_tool.py search --era 宋代 --limit 8
python -X utf8 scripts/history_tool.py search --person 韩信
python -X utf8 scripts/history_tool.py search --template T2 --exclude-cluster 韩信之死 --limit 5
python -X utf8 scripts/history_tool.py search --query "刘询 霍光"
python -X utf8 scripts/history_tool.py read H003 H012 H022 H031 H047
python -X utf8 scripts/history_tool.py hooks --type K1 --limit 5
python -X utf8 scripts/history_tool.py hooks --person 韩信
python -X utf8 scripts/history_tool.py hooks --type K2 --include-secondary --era 西汉
python -X utf8 scripts/history_tool.py hooks --id H003
python -X utf8 scripts/history_tool.py count "正文.txt" --target 1000
python -X utf8 scripts/history_tool.py count "正文.txt" --target 1000 --tolerance 0.05
python -X utf8 scripts/history_tool.py audit "正文.txt"
python -X utf8 scripts/history_tool.py scan "用户指定的新素材目录"
python -X utf8 scripts/history_tool.py validate
```

`search`：各过滤条件同时满足；时代匹配完整标签及文档列明的别名，人物精确匹配，冲突可包含片段。查询词按空格分开且全部命中。无结果就是无结果，不偷偷放宽条件。默认按相关度并兼顾账号和故事簇多样性，返回路径和事实风险。需要扩大样本时助手另行查询同模板。`read` 默认原始全文，`--clean` 仅用于查看清洗版，不能替代写作前的原文阅读。

`count`：整个文件视作正文，不自动识别标题、脚注或 Markdown。默认统计字母和数字，不计标点空白；`--include-punctuation` 改为所有非空白字符。容差默认为零，目标不符退出码为 1，参数或文件错误为 2。不要把含资料备注的 Markdown 文档作为严格正文计数文件。

`hooks`：从全量开头标注检索，`--type K1` 至 `K9` 默认只匹配主类型，`--include-secondary` 也匹配辅助标签；可叠加精确人物、时代和 ID 条件。默认返回 5 条，兼顾账号与故事簇分散，无结果不自动放宽。含早期文字窗口、完整引题单元、正文承诺、风险、原文路径与时长估算口径；完整单元可能远超前几秒。命中结果不能视为事实包或效果排名。

`audit`：剔除非字母数字后，用连续 5 字片段集合比较，返回重合比例与片段；没有自动通过阈值，也不能检出所有语义套写。短于 5 字时没有有效片段，不能据低重合宣称原创。核对引文、固定人名及常用表达后判断是否需要改写。

`scan`：只读所有 Markdown 文件并计算 SHA256。相同内容可识别改名，旧文件名的新内容标为变化候选；既改名又改内容可能列为新增，需人工按视频 ID 合并。不会改写源目录，也不会删除库内文件。

`validate`：检查必需字段、ID 唯一性、库内相对路径、原件哈希、逐篇元数据与总目录一致性；还检查开头分析覆盖全部 ID、来源与检索标签一致、引题单元确为正文原文前缀及其字数。不证明语义分类唯一正确、史实正确或新稿质量。统计文件是一次分析快照，增量更新需按维护流程重算。
