# 核验事实包

以下为实际读取的维基文库古籍转录中的有限主张，不是 57 篇文稿的全面事实认证。网页属于公开转录，重要异文须进一步对照校勘本。古籍原文与现代阐释分开使用。

## F1 韩信：职位变化与钟室记载

出处：[《史记》卷九十二·淮阴侯列传](https://zh.wikisource.org/wiki/史記/卷092)。本次读取全文。

| 关键原文 | 可以支持的叙述 | 不支持的扩写 |
| --- | --- | --- |
| 至拜大將，乃韓信也，一軍皆驚。 | 韩信拜大将出乎众将预料 | 所有人早就轻视他的内心独白 |
| 漢王奪兩人軍，即令張耳備守趙地。拜韓信爲相國，收趙兵未發者擊齊。 | 修武取军后仍交给韩信攻齐任务 | 战时取军就已证明刘邦决定日后杀韩信 |
| 漢方不利，寧能禁信之王乎？不如因而立，善遇之，使自爲守。 | 张良、陈平以局势劝刘邦接受韩信称王 | 封王仅由喜爱或感激决定 |
| 項羽已破，髙祖襲奪齊王軍。 | 击败项羽后，刘邦夺取韩信的军队控制 | 韩信当夜已决定谋反或刘邦早有杀人计划 |
| 徙齊王信爲楚王，都下邳。 | 韩信由齐王改为楚王 | 官爵名称可以不经核对任意替换 |
| 至雒陽，赦信罪，以爲淮陰侯。 | 云梦会见被捕后，到洛阳获赦，降为淮阴侯 | 失势仅由一句话引起 |
| 信乃謀與家臣夜詐詔赦諸官徒奴，欲發以襲呂后、太子。 | 本传确实记有韩信谋反叙事，须交代 | 所有案情均已获得现代独立证据确认 |
| 呂后使武士縛信，斬之長樂鐘室。 | 本传行刑地点与方式表述 | 竹竿、宫女、“三不杀”承诺 |
| 髙祖已從豨軍來，至，見信死，且喜且憐之。 | 刘邦回军见韩信死，本传记其复杂反应 | 刘邦当场指挥钟室行刑 |

注意“且喜且怜”对应韩信死后的反应，不能错配到此前获赦。若只用这些材料，最好从兵权、封国、爵位变化切入，不写心理全知小说，也不裁定全部争议。

## F2 贾诩：慎交、劝谏与立嗣问答

出处：[《三国志》卷十·魏书·荀彧荀攸贾诩传](https://zh.wikisource.org/wiki/三國志/卷10)。实际阅读贾诩部分及相关裴注；不声称全卷所有人物均完成核验。

| 关键原文 | 可以支持的叙述 | 限定 |
| --- | --- | --- |
| 詡自以非太祖舊臣，而策謀深長，懼見猜疑，闔門自守，退無私交，男女嫁娶，不結髙門。 | 本传将其慎交与担心猜疑联系；不攀高门婚姻 | 不等于任何场合都不说话，更不等于给所有人提供普适保命术 |
| 願將軍恢崇德度，躬素士之業，朝夕孜孜，不違子道。如此而已。 | 曹丕问自固之术，贾诩劝其修德、守子道 | 白话转述不伪装为逐字原句 |
| 思袁本初、劉景升父子也。 | 曹操问时，贾诩以袁绍、刘表父子作答 | 不能据一句话独占整个立嗣过程的因果解释 |
| 太祖不從，軍遂無利。 | 本传叙曹操未从贾诩南下前的建议 | 裴注对该建议有不同评价，不写成谋士永不失算 |
| 此救命之計，何功之有！ | 李傕等欲封侯时，贾诩自称救命之计并辞赏 | 是传中归于人物的话，不代表后人必须接受其道德自辩 |

裴松之对劝李傕等西攻长安的评价包括“詡之罪也，一何大哉”；若写贾诩一生功过，需纳入建议的公共后果，不能只以个人善终评判所有谋略。试写只讨论慎交与表达，不由此称其一生无过。
