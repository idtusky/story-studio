# 史实与素材

## 从故事问题走向证据

原稿用于研究叙述方式。新稿写什么事实，由实际核对的材料决定。先列支撑论点和情节的关键主张，通常从 3–8 条起步，按实际信息量增补，不以数量作为核验上限。可外部查证的叙述都应有依据；同一来源支持的普通背景可合并记录，决定开头、转折和结论的主张逐条记录。短稿可更少，不为了形式堆来源。

在本次项目目录保存事实核查表，最小字段为：`ID｜拟用主张｜来源及定位｜原文或忠实摘要｜材料层级｜核查状态｜支持范围与疑点｜成稿采用表述`。来源定位写书名、卷篇与所用版本，纸书可记页码，网页记可追溯链接及访问日期；摘要须注明是摘要，不伪装引文。复用事实包时记录条目与实际支持范围，不扩张成该人物生平已全部核实。

状态使用“已核对出处”“存在分歧”“未核实”“与所查证据不符”。“已核对出处”只表示核实了材料如何记载，不代表已证明历史现场完全如此。不要给主观置信百分比冒充验证结果。

优先核对决定情节的姓名、年代、官职、人物关系、死亡方式、工程规模、直接引语。时代制度宜查专业研究，文物数据优先官方考古或博物馆材料。可访问的原典转录便于定位，但不等于校勘定本；重要异文或争议须对照版本。多个网页复述同一故事不等于多个独立证据。

实际读到支持主张的段落及必要上下文，不能只看搜索摘要、书名或他人引述。先检查来源时代、作者、体裁与记述范围；原始史料也可能有立场、传闻和讹误，不因“正史”二字免审。关键争议、极端数字、唯一性断言、死因与私下对白，尽可能对照不同来源或可靠校勘研究；找不到独立支持时缩小论断、注明材料归属或不用，不为凑两条来源把同源转载重复计算。版本分歧不能仅按来源数量投票。

## 写前的事实边界

- **时间与身份：** 按“时间／人物当时身份／事件／来源”列必要时间线。核对即位、任官、封爵、去世与事件的先后，不用后来的身份解释当时权限。区分虚岁周岁、年号与公历；跨公元前后没有公元 0 年，历法换算不凭印象给出精确月日。不确定的日期保留材料精度。
- **制度与空间：** 同名官职在不同朝代未必同权，同姓未必同族，今地名不能无说明替代古代疆域。核对当时行政归属、路线和人物能否在场，避免人已去世却参与后事。
- **数字与范围：** 区分史籍所称、现代估算与确切测量；核对单位、分母、时间范围。“百万”“全部”“唯一”“从未”承担额外举证责任，不能用模糊的“据说”保留无依据的刺激数字。
- **引语与场景：** 直接引用核对字句、说话人、对象和语境。白话转述用叙述语气，不造逐字对白；史事稿不添加无记载的密谈、表情、动作和临终心理。“可能”“或许”也不能为无证场景兜底。
- **因果与评价：** 先后发生不自动证明因果，后来获利不自动证明策划，结果不证明人物早知结局。解释须给可查行动、条件与后果，保留影响结论的反证；不用“功高必死”“三百年必亡”概括所有情况。

开头和选题的问题前提同样是主张。“赵云为何一辈子进不了核心圈”须先定义并核对“核心圈”；“谁用竹竿杀韩信”已预设竹竿属实。前提不成立时，换问题或给有来源的辨析，不用问号绕过事实审查。多版钩子共用已核事实池，每版新增的前提仍须检查。

## 表述分层

| 材料 | 成稿处理 |
| --- | --- |
| 史籍明确记载 | 可据此叙述；高争议处说清“某书记载”，不把史籍叙事等同无误现场记录 |
| 注引异说 | 交代是注引哪一种材料，与正文不同则保留差异 |
| 《三国演义》等小说 | 明说小说情节，并核对原著是否确有该段 |
| 民俗与民间传说 | 说明版本或地区，不当作统一史实 |
| 新编历史故事 | 先标文学演绎；对白、场景可以创作，不伪称史书发现 |
| 作者解读 | 用“从这些行动看”“一种解释是”等限定，提供事实环节和可能反例 |
| 无可靠依据 | 从默认史事成稿中删掉或更换切口；仅在用户明确要求待核草稿时就地标记，不暗示必有秘史 |

正文逐字引语必须核过原文；白话转述不放成伪原句。宫廷密谈、临终想法、具体眼泪神态尤其容易被误当记载。史料没有记载，只能说本次所查材料未载，不能推断“史官不敢写”。

存在分歧时，交代影响本题的不同记载及各自出处，或收窄到共同支持的部分；不擅自裁成唯一真相。通俗口播无需句句插来源，可在争议处自然说“《某书》记载”“某注引另一说”。小说情节不是史实，“演义”也不等于任意新编：引用小说仍要核对原著，新增内容另标文学演绎。用户仅说“生动”“有画面感”不等于授权虚构。

## 本库需要特别分开的案例

- H031/H042：本次所查《史记·淮阴侯列传》记“斩之长乐钟室”，未载竹竿、宫女、“三不杀”说；不据此断言所有后世文献都无此传说。原典有谋反叙事，不能有选择地删去后称韩信绝无谋反。
- H016/H046：貂蝉是文学角色；曹营三条件谈判不能默认来自《三国演义》原著。可作为明确新编，不能写成“史官隐藏的真实结局”。
- H023：空城计的现代“默契放水”解读，不等于正史或小说原著证明双方合谋。
- H040：疾病卒不能自动推出曹丕谋杀；正文、裴注和作者推测分别标注。
- H003/H015：许平君死、霍光死、霍氏败亡三项日期先列时间轴，不能将不同起算点的年数混在一起。
- H026：污物清运、雨水排放、地上沟与地下沟分开，避免否认地下管道后又解释暗沟。
- H049/H050：同姓不代表同一皇族支系；灭亡不等于姓氏或血脉全灭。H049 的两种子婴死法互相冲突。
- H056：核对引用书的时间范围，不能借原版《资治通鉴》为南宋岳飞、明代袁崇焕的具体故事背书；须找实际记载这些人物的来源。
- H038：当代人物的近期活动、引语和数字必须查可追溯报道，不能按古代传说自由补写。

这里大部分是需要核对的风险提示，不是全部完成的史实纠错清单。已核对的少量原文另列 [核验事实包](核验事实包.md)。每篇 `risk` 仍须读取。

## 无法联网时

可以使用实际读到的本地可靠材料，或在已核事实包列明的主张内写。若某题证据不足，先完成有依据的部分，说明具体缺哪条材料，并提供可行的结构或替代切口；用户明确要待核草稿时才写，并在未核处标注。不能把记忆中的书名、猜测的网址和未经阅读的搜索摘要伪装成已核出处，也不以“史料有争议”掩饰尚未查资料。

## 交付核验

从最终稿逐段反查事实表，覆盖标题、选题句、每版开头和正文；格式化之后还要检查是否产生新主张。核验次序如下：

1. 每个关键断言是否被实际阅读的出处支持？史书范围、章节、引文归属及材料层级是否正确？引用书名不能代替证据。
2. 时间、当时身份、人物关系、地理与制度是否互相兼容？数字与限定范围是否在缩写中丢失？
3. 是否把单一记载当无争议结论、把作者判断当人物心理、把文学情节当史实？是否隐去了会改变结论的反证？
4. 开头承诺是否由正文实际证据兑现，而不是越讲越夸大？检查最抓人的一句和最确定的一句，依据不足先重写。
5. 字数与口语润色后再查最终变更。扩写只能增加已核信息；字数不足时补核材料或调整结构，不用新编场景凑数。

存在尚未解决的关键无依据断言、引文错配或时间线矛盾时，不把稿件标成核验完成。可纠正或删去的先完成；剩余局限说明到具体主张。用户只要纯口播时，证据表留在工作目录，必要的争议限定仍在口播本身。工具 `validate` 只检查文件与语料一致性，不具备历史真伪判定能力。
