# 文章结构模板

先选能回答本篇核心问题的骨架。以下结构来自逐篇人工标注，不是要求每篇按同一比例分段。各篇完整骨架见 `corpus/meta/` 的 `structure`。

T1–T6 描述整篇推进；[开头钩子](开头钩子.md)的 K1–K9 描述开头制造期待的机制，同一结构可换不同开头。先检查这一版承诺能否由正文兑现，再选择入口，不用类型编号替代判断。

## T1 命运回溯

证据：H003、H007、H009、H015、H030、H031、H035；回查 H022、H044、H038。

异常结局或处境 → 回到与问题有关的起点 → 两三次关键选择 → 处境随之改变 → 回到开头。

开头可把前后待遇并置，如厚葬与家族失势。第一转折不是“他出生了”，而是命运条件改变的具体事件。中段写谁做了什么，使下一步变容易或变难。收束解释变化，避免把结局当“报应”。H007 用道具贯穿，H015 用接力帮助推进，说明本模板不必总是权臣惨死。

可用开头：同一个人，前一阶段被托付要事，后来却失去了独立调动部属的权力。这中间发生了什么？实际稿件须填入已核实的具体职位与事件，不能直接照抄空架子。

## T2 困局拆解

证据：H010、H018、H023、H027、H032、H040、H041、H052–H055；回查 H005、H014、H019、H050。

矛盾 → 各方处境、资源、选项 → 一项决定改变关系 → 由行动或制度解释结果。

将抽象判断拆成可验证的环节。H027 的“三本账”提供视角切换；H041 从依赖说明代理关系；H018 用具体建议表现原则。它们可共享困局结构，但不可共享一套“你太聪明，所以必须死”的答案。

H023、H040 的反常识开头很强，证据却不足以支持阴谋定论。新稿可以讲“为何出现这种解读，以及史料支持到哪一步”，不能拿悬疑问题暗示已有凶手。

## T3 主题盘点

证据：H001、H006、H021、H037、H045；回查 H008、H036、H056。

限定比较标准 → 每人一件独有行动、一种后果 → 对照异同 → 回答开头标准。

两人比较也属于本型。先选标准，再选人；“聪明”“悲惨”“忠诚”需要落到能比较的维度。若用名次，开头说明个人评价依据，不能称客观历史排名。每一项应提供新信息，不能十人都以“功劳太大、皇帝害怕”结束。

续篇只有实际存在且用户要系列时才承接，单篇须兑现自身承诺。H001/H008 是同题簇，不是两份独立证据。

## T4 贡献重估

证据：H012、H020、H029、H043；回查 H028。

熟悉标签 → 一项不同尺度的贡献 → 运作机制 → 当时的成本和局限 → 有边界的判断。

从“谁留下了什么”进入“它为什么能发挥作用”。H029 跨秦明近代，提醒不同年代的长城不能混成一种材料与制度。H043 的当世成本与后世遗产适合双面评价，但不能用“若多活几年必然如何”证明贡献。

## T5 器物知识（暂定）

仅 H025、H026 两篇，尚不足以断言稳定风格。

眼前实物或日常问题 → 自然或工程约束 → 设计如何应对 → 可观察结果及局限。

每篇短稿只解释一个系统。故宫雨水排放与污物清运分别处理；不能开头否认地下系统，后文又用暗沟解释排水。数字、建造周期、“第一”称号均须核实。无视觉素材时不能声称镜头已经拍到某处细节。

## T6 民间故事（暂定）

H024 是道具解题，H057 是神话民俗，合计两篇且内部差异明显。

道具或习俗提出问题 → 人物尝试 → 受阻 → 改变方法或付出代价 → 回扣问题。

讲民间故事先说明版本性质；民俗知识另查出处。允许用户要求的新编对白与场景，但不能署为史传原句，不将民俗版本归纳为全国唯一习俗。

## 字数适配（新技能的编辑策略）

| 目标正文 | 建议信息量 |
| --- | --- |
| 300 字以内 | 单一问题、一次行动和后果，省去完整生平 |
| 301–600 字 | 一个事件，两步因果；不做十人榜单 |
| 601–1200 字 | 一个主问题，两三项证据，可加入一处争议边界 |
| 1201–2000 字 | 三四个关键节点，或三人有区分的比较 |
| 2000 字以上 | 扩展背景、反例和来源差异；仍围绕一个主问题 |

这不是原作者比例统计。先选择足够的真实内容，再分配字数；扩写增加信息，缩写删除支线，均不靠密集反问填充。
