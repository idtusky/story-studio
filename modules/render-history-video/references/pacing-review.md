# 节奏复核与修正

全部画风执行相同时间规则。先根据真实音频与已核验 SRT/Coli 对齐建立 start/end，再检查节奏，不把全片等分当作对齐。无音频但已有可靠 SRT 可制作静音草稿并说明依据；两者均无则只做待对齐计划，不能运行无输入的转录或声称精确对齐。

先执行 [逐镜语义对齐](semantic-alignment.md)；语义不符时不得为通过时长检查提前或延后事件画面。

1. 核对文稿版本、重复锚点出现次序、镜头原文与画面主动作。若 SRT 一条包含多个镜头，不能将这些镜头都放在该条起点，也不能按字数插值伪装精确切点；选择可证实的语义边界，或记录未解决的精度限制。音频与稿件版本不同，先记录遗漏/新增句及匹配方案。
2. 默认目标 8 秒/图，常规 5–12 秒。固定 N 时用总显示时长/N 作相对均衡基线，但仍报告绝对过快/过慢。短于 3 秒、长于 16 秒、相邻时长比超过 2、连续三镜不足 5 秒、末两镜积压均需复查。用户指定节奏优先，例外记录具体语义和时长；不得因为漫画或黑白风格而忽略。
3. 执行 `py -3.11 "<skill目录>/scripts/check_pacing.py" "<版本目录>/plan.json"`，把 JSON 输出保存为 pacing_report.json。退出码 0 仅代表数值范围通过，1 为需复查，2 为输入无效。该脚本不验证字幕语义、图片内容或配音总长度，仍需原有验证。
4. 在已授权的剪辑范围内调整切点时，必须有语义依据并保留连续音频；不要把下一事件的图片提前凑时长。已授权修复分镜时，先合并同事件短镜、释放镜数补到长段，固定数量不变；更新分镜范围、锚点、提示词与图片映射。需要新图但没有生图授权时，写出补图清单和完整提示词、注明草稿尚有节奏缺口。不要以重复图片、换画风、加速配音或循环推拉冒充修复，也不擅自丢弃用户指定图片。
5. 短于 5 秒的镜头默认显式设置 cut_punch: false；用户明确指定短镜冲击时保留并复核裁切。慢推拉幅度按实际时长乘 0.0065，上限 16%，贴边人物上限 12%，取消 10% 下限。开关和 zoom 写入 plan，剪映与本地渲染共用。
6. 修正后重跑检查，保存保留异常的逐镜解释；重点看最短镜、最长镜、连续短镜和切点两侧的口播与画面。报告真实验证范围，不能把数值通过写成已观看播放。
