# 渲染计划

所有相对路径相对于 plan.json。必须先由 agent 根据 SRT 语义生成镜头时间；脚本不猜测语义。start/end 单位秒，分镜连续且从零开始，量化到最近帧后仍须连续。

导出前按 [逐镜语义对齐](semantic-alignment.md) 形成语义核验记录；start/end 使用核验后的显示边界，不直接把第一镜 audio_start 当作画面起点。

```json
{
  "width": 1080,
  "height": 1920,
  "fps": 30,
  "crf": 18,
  "audio": "../../narration.mp3",
  "shots": [
    {"id": "S001", "image": "../../S001.png", "start": 0, "end": 19.9,
     "anchor": "SRT 对应的第一句", "zoom": [1.0, 1.12], "pivot": [0.5, 0.45]},
    {"id": "S002", "image": "../../S002.png", "start": 19.9, "end": 36.3,
     "anchor": "下一段开始", "zoom": [1.12, 1.0], "pivot": [0.5, 0.5]}
  ]
}
```

- audio 省略或 null：输出无声视频。找到明确对应配音时默认使用，不擅自生成旁白或加入音乐。
- zoom：相对于铺满画幅的缩放，两个值均至少为 1。脚本在该镜推拉段上从第一个值插到第二个值。pivot 是剩余裁切量在横纵方向的分配，范围 0–1；0 靠左/上，1 靠右/下。
- 切点冲击缩放（默认开）：图片硬切时保留冲击（出镜推近、进镜拉回），但进镜/出镜都走慢时长。计划级默认 `punch_in: 1.50`（约 1.80s）、`punch_out: 1.28`（约 1.00s）、`cut_punch_anim: false`。不要默认开动感入出场，切点会闪黑。单镜可覆盖这些字段，或设 `cut_punch: false` 关掉。视频镜头默认不加。短镜会自动缩短冲击时长，避免吃掉推拉。
- 默认手感：约 16–20 秒完成一次 12% 推或拉。`amp = min(0.0065 × (end-start), 0.16)`；贴边人物 amp≤0.12。邻镜用 `[1.0, 1+amp]` 与 `[1+amp, 1.0]` 交替。禁止把整段推拉压进前几秒。
- 图片与输出比例不同：等比铺满、按 pivot 裁切，不拉伸。检查主体，用户要求全图可另行实现留边方案。
- 输出长度以末镜 end 为准，不允许短于配音（容差 1 帧），应至少覆盖 SRT 最后一条结束时间。勿为凑整而截断。
- 宽高必须正偶数。fps 为 1–120 的整数，默认 30。最后按帧计数，时间误差最多半帧。
- 默认把同一份 plan 写成剪映草稿，不生成 final.mp4。草稿由内置脚本直接使用pyJianYingDraft生成。
- 剪映草稿的 zoom/pivot 与本地渲染含义相同：铺满画幅后再推拉，关键帧覆盖整段停留时间；切点另写冲击缩放关键帧。路径与限制见 [jianying.md](jianying.md)。

生成计划后按 [节奏复核](pacing-review.md) 运行 check_pacing.py。短于 5 秒的镜头默认关闭 cut_punch，除非用户明确要求短镜冲击；不要把冲击时长压短而保留大幅缩放。zoom 幅度没有 10% 下限，4 秒镜按默认速度仅约 2.6%。
